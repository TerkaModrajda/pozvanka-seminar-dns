DNS – seminář (nejen) o kybernetické bezpečnosti

Pro Netlify nahrajte obsah této složky tak, aby index.html byl v kořeni webu.

- Všechny původní odkazy (registrační formulář, kontakt) zůstaly zachované.
- QR kód vede na stejný odkaz (https://hqr.la/eebf5a8d), je jen přebarvený do DNS modré. Ověřeno dekódováním.
- Generování PDF je převzaté z původní verze beze změny logiky, upravené jsou jen barvy (DNS modrá).
  PDF se skládá z aktuálního obsahu stránky v okamžiku kliknutí a rovnou se stáhne.
- PDF funguje na webu (Netlify / lokální server). Při otevření index.html dvojklikem ze složky ho prohlížeč zablokuje.
